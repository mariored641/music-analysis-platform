# MAP 2 — רימייק חוויית המשתמש

מקור אמת: [`VISION.md`](VISION.md). המסמך הזה מתאר איך הרימייק מממש את החזון.

## עיקרון מנחה
**בחירה → תיוג → רואים מיד → נשמר.** כל פעולת ניתוח צריכה להיות קליק אחד או מקש אחד אחרי הבחירה.
אין חלונות עם "Apply", אין קליק ימני חובה, אין לשוניות שצריך לחפש.

## מבנה מסכים

### ספרייה
- גריד כרטיסים: שם, מחבר, ז'אנר, סולם/משקל/תיבות, כמות תיוגים, נפתח לאחרונה.
- חיפוש חופשי, מיון (שינוי אחרון / פתיחה אחרונה / נוסף / שם / מחבר / ז'אנר), סינון צ'יפים לפי ז'אנר ומחבר.
- העלאה: כפתור או **גרירת קבצים לכל מקום בחלון** (MusicXML / MXL, כמה בבת אחת). קובץ בודד → טופס מטא-דטה ממולא מראש מה-XML.
- תיקיית סנכרון: חיבור תיקייה במחשב; כל יצירה נכתבת כ-`<שם>/<שם>.musicxml` + `<שם>.analysis.json`. "ייבוא מהתיקייה" מוסיף יצירות שקלוד קוד (או כל אחד) שם בתיקייה.

| קליק על תו | בחירת תו |
| קליק על אזור ריק בתיבה | בחירת כל התיבה |
| Shift+קליק | הרחבה מהעוגן |
| Ctrl+קליק | הוספה/הסרה של תו |
| גרירה | לאסו |
| ←/→ | מעבר לתו הקודם/הבא |
| Shift+←/→ | הרחבה/צמצום תו-תו |

הבחירה מסומנת בפס הדגשה (כמו בחירת טקסט) + ראשי תווים צבועים.

## QuickTagBar — התיוג המהיר
סרגל צף מעל הבחירה. שורה ראשונה: האקורד המזוהה (קליק = הוספה), ואז קטגוריות:
אקורד (H) · תפקיד מלודי (N) · מוטיב (M) · חלק/מבנה (F) · תווית (T) · שאלה (Q) · צבע (K) · הערה (Enter ב-Notes).
פתיחת קטגוריה מציגה שורת אפשרויות — **קליק אחד מחיל**. בתפקיד מלודי: מקשים 1–8 מחילים CT/PT/NT/…
קליק ימני פותח את הסרגל במיקום העכבר.

## תיוגים על הדף
- הרמוניה: טקסט מעל החמשה, ספרה רומית מתחת לסימן. בחירה → קו מקווקו לתו העוגן + ידית עוגן שאפשר לגרור לתו אחר (המיקום ה"אמיתי"). Alt+←/→ מזיז את העוגן.
- מלודיה: צביעת ראש התו לפי התפקיד.
- מוטיב: "בועה" סביב התווים + תווית (A, A inv…).
- מבנה/מרקם: פס מתחת למערכת עם שם החלק.
- תווית: סוגר מעל התווים עם הטקסט. שאלה: סוגר מקווקו עם "?".
- כל תיוג נגרר (מיקום ויזואלי), דאבל-קליק מחזיר למקום. Delete מוחק תיוג נבחר.

## פאנלים
- **שכבות (שמאל)**: 👁 הצגה/הסתרה, 🎯 "סולו" (רק השכבה הזו), ▸ מקרא נשלף עם צבעים ניתנים לעריכה. בשכבת הציור — כל צבע שהשתמשת בו מופיע אוטומטית, אפשר לתת לו טקסט ולשייך לשכבה אחרת (קווי ציור משויכים מוצגים גם כשרק השכבה המשויכת דולקת).
- **ימין — בחירה**: התווים, האקורד, וכל התיוגים שחלים על הבחירה (עריכה/מחיקה). בלי בחירה: סקירה — סיכום שכבות, שאלות פתוחות, מוטיבים (קליק = קפיצה).
- **ימין — הערות מחקר**: פסקאות טקסט חופשי; כל פסקה מקבלת קישורים לבחירה הנוכחית; קליק על קישור → קפיצה + בחירה בפרטיטורה.

## ציור (סטיילוס)
עיגולי צבע בפינה הימנית-תחתונה של הפרטיטורה. **עט מגע מצייר תמיד** (עכבר/אצבע בוחרים), או מצב ✎ שגם העכבר מצייר. קליק על עיגול פעיל → חלונית עובי/אטימות/צבע שנסגרת בקליק בחוץ ושומרת. מחק (E) מוחק קו בלחיצה.
קווים נשמרים בקואורדינטות של הדף (רוחב קבוע) — יציבים בכל זום וגודל חלון.

## נגינה
Space מנגן מהבחירה (תו או תיבה), שוב Space = עצירה זמנית. 🔁 מלופּ את הבחירה. סמן נע על התווים + גלילה אוטומטית.

## שמירה וייצוא
שמירה אוטומטית (~1 שניות) ל-IndexedDB + לתיקיית הסנכרון אם מחוברת; "נשמר ✓" ב-TopBar; שמירה גם ביציאה מהדף.
ייצוא: PDF (הדפסה עם התיוגים), JSON (`.analysis.json` מלא, קריא לקלוד קוד).

## סקריפטים (🔬)
מגירה עם כרטיס לכל סקריפט: תיאור, דרישות (למשל "34 אקורדים זמינים ✓"), הרץ / נקה, תוצאה בשורה.
- תפקידים מלודיים (CT/PT/NT) — כותב לשכבת המלודיה.
- זיהוי מוטיבים — לפי מוטיבים מתויגים, או "מהבחירה". סף התאמה + טרנספורמציות.
- ספרות רומיות / מציאת אקורדים.

## הערות טכניות
- הפרטיטורה מרונדרת ע"י OSMD לרוחב לוגי קבוע (`PAGE_WIDTH`), והזום הוא `transform: scale` — כל הגיאומטריה (תיוגים, ציור) בקואורדינטות לוגיות.
- מזהי תווים: `note-m{index}b{beat*100}-{step}{oct}[-s{staff}][-p{part}]` — `m` = אינדקס תיבה (1-based) בסדר המסמך.
- תיוגים ישנים מומרים בטעינה (`services/migrate.ts`): `noteColor{colorType}` → `melody{noteFunction}`.
